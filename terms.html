Hermes Workspace — 최종 갱신 2026-11-12

1. 목적

Hermes Workspace는 소유자 본인이 개인 서버에서 운영하는 AI 비서가 본인의 Google 계정 데이터에 접근하도록 연결하는 개인용 OAuth 클라이언트입니다. 제3자에게 제공되는 서비스가 아닙니다.

2. 사용

이 앱은 소유자 1인만 사용합니다. 소유자는 자신의 Google 계정 권한을 언제든지 철회할 수 있으며, 철회 시 앱의 접근은 즉시 종료됩니다.

3. 보증의 제한

이 앱은 개인 용도로 "있는 그대로" 제공되며, 상업적 보증이나 특정 목적 적합성에 대한 보증을 하지 않습니다. 자동화된 작업의 결과는 사용자가 직접 확인해야 합니다.

4. 책임

앱 사용으로 발생하는 데이터 변경(메일 발송, 일정·문서 수정 등)의 최종 책임은 소유자에게 있습니다.

5. 준수

이 앱은 Google API 서비스 약관과 Google API 서비스 사용자 데이터 정책을 준수합니다.
