Hermes Workspace — 최종 갱신 2026-11-12

1. 적용 범위

본 방침은 개인 사용자가 자신의 개인 서버에서 운영하는 AI 비서(Hermes Agent)가 Google 계정에 접근할 때 적용됩니다. 이 OAuth 클라이언트는 단일 사용자 본인만 사용하며, 일반에 공개된 서비스가 아닙니다.

2. 접근하는 Google 사용자 데이터

  • Gmail 메일(읽기·보내기·라벨/읽음 상태 수정)
  • Google 캘린더 일정
  • Google 드라이브 파일
  • Google 연락처
  • Google 스프레드시트 및 문서

3. 이용 목적

사용자가 요청한 개인 업무 보조 기능(메일 요약, 일정 확인, 문서 편집, 메일 발송 등)을 수행하기 위해서만 데이터를 사용합니다. 광고, 프로파일링, 모델 학습 목적으로 사용하지 않습니다.

4. 저장과 보호

OAuth 접근 토큰과 처리 결과는 사용자가 직접 관리하는 개인 서버에만 저장되며, 파일 권한으로 보호됩니다. 비밀번호는 저장하지 않습니다. 데이터는 암호화된 통신(HTTPS)으로만 전송됩니다.

5. 제3자 제공

수집한 Google 사용자 데이터를 판매, 대여, 양도하지 않습니다. 사용자가 명시적으로 요청한 작업을 수행하기 위해 AI 모델 제공자에게 전달되는 경우에도 해당 작업에 필요한 최소 내용만 전달하며, 비밀번호·인증 토큰·결제 정보는 전달하지 않습니다.

6. 보관과 삭제

데이터는 사용자가 삭제하거나 접근 권한을 철회할 때까지 보관됩니다. 사용자는 언제든지 Google 계정 권한 페이지에서 이 앱의 접근 권한을 철회할 수 있으며, 철회 즉시 새로운 접근은 불가능해지고 서버에 저장된 토큰은 폐기됩니다.

7. Google API 서비스 사용자 데이터 정책

이 앱은 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)과 제한적 사용 요구사항을 준수합니다. 제한적 스코프로 받은 데이터는 사용자가 요청한 기능 제공 목적 외로 사용하거나 전송하지 않습니다.

English summary

Hermes Workspace is a single-user OAuth client used by its owner's personal AI assistant running on the owner's own server. It accesses Gmail, Calendar, Drive, Contacts, Sheets and Docs only to perform tasks the owner asks for. Data is stored locally on that server, is never sold or shared with third parties, and is not used for advertising or model training. Access can be revoked at any time at myaccount.google.com/permissions, after which stored tokens are discarded. This app's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Contact: fighter.top@gmail.com
